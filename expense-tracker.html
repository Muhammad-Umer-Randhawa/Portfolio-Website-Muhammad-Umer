Expense Tracker

A Java Swing desktop application for managing personal expenses. It connects to a MySQL database through JDBC, lets you log expenses under spending categories with monthly budgets, and tracks your monthly salary and savings. A dashboard shows live-updating totals so you always know where your money is going.

Features

  • Add, view, and delete individual expenses
  • Organize spending into categories, each with its own monthly budget
  • Record monthly salary and track savings over time
  • Dashboard with live-updating totals for the current month

Built with

Java Swing JDBC MySQL

What I'm proud of

Getting the dashboard to update in real time as expenses come in was the most satisfying part. Designing the database schemas and wiring them up with JDBC taught me a lot about how desktop apps talk to relational databases.
