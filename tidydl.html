TidyDL

My Downloads folder was a mess. Lots of files with no organization. So I built a small Windows tool that runs in the background and sorts everything automatically. It shipped as a standalone .exe that can be set to run at startup, and it solved the problem completely.

Features

  • Sorts files into subfolders by type (images, documents, installers, etc.)
  • Deletes exact duplicate files
  • When file names match but content differs, keeps both and numbers the new one (e.g., "report (1).pdf")
  • Finds the real Downloads folder even if it has been moved from the default location
  • Prints a short summary of what it did
  • Ships as a standalone .exe that can run automatically at Windows startup

Built with

Python Windows APIs PyInstaller

What I'm proud of

This was a problem I actually had, and writing a tool to fix it felt great. The tricky parts were figuring out Windows' real Downloads path (since users can move it) and handling the edge case where two files share a name but are different—deleting the wrong one would have been a bad surprise.
