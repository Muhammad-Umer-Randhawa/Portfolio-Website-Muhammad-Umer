Book Text Analytics Engine

A Java command-line tool that takes a plain-text book file and pulls it apart: word counts, frequency rankings, neighbor analysis, prefix search, and page-and-line lookups. I built it to practice data structures and algorithms, implementing tries, AVL trees, and a custom hash table from scratch instead of using library collections. It was a hard and good challenge.

Features

  • Total and unique word counts
  • Most frequent words ranking
  • Neighbor word analysis (words that appear next to a given word)
  • Prefix search powered by a hand-built Trie
  • Word lookup by page and line range using an inverted index backed by an AVL tree
  • Custom hash table implementation
  • Benchmarker comparing naive vs. optimized approaches

Built with

Java Trie AVL Tree Hash Table Inverted Index

What I'm proud of

Implementing every data structure from scratch—no java.util shortcuts—was the whole point, and also the hardest part. Getting the AVL rotations right for the inverted index took several tries, and the benchmarker showed exactly how much difference the optimized structures make compared to brute-force searches. It made the theory feel real.
